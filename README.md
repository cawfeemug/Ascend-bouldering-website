# 🧗 Ascend Bouldering Gym Website

A modern, responsive front-end website for a fictional bouldering gym, **Ascend**, developed as part of a **Web Fundamentals** assignment. The project showcases the use of HTML, CSS, and JavaScript to create an engaging and interactive user experience with smooth animations, intuitive navigation, and client-side functionality.

---

## Features

### Home Page

* Modern landing page with smooth scrolling and animated transitions
* Earth-tone color palette inspired by natural climbing environments
* Functional embedded Google Maps location for the gym
* Responsive navigation and layout

### First-Timer Guide

* Information for new climbers
* Introduces basic bouldering concepts and what visitors should expect
* Beginner-friendly layout and design

### Pricing

* Clear membership and day pass pricing
* Organized and easy-to-read pricing cards

### Meet Our Staff

* Introduces the gym's staff members
* Clean profile card layout with responsive design

### Contact Us

* Interactive contact form
* Allows users to enter their details and messages
* Client-side validation for user input

### User Authentication

* Functional Sign Up and Sign In system built with JavaScript
* Input validation and error checking
* Prevents invalid or incomplete submissions
* Demonstrates client-side form handling and authentication logic

---

## Technologies Used

* **HTML5** – Website structure and semantic markup
* **CSS3** – Styling, responsive layouts, transitions, and animations
* **JavaScript (ES6)** – Interactive functionality, form validation, and authentication logic
* **Google Maps Embed API** – Gym location integration
